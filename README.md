# Jellyfin

## Overview
Self-hosted media server providing streamlined and remote access to disks I have burned, and VHS tapes that I didn't want to keep.

## Deployment
- Runs as an LXC container on the Proxmox cluster.
- Reachable remotely without direct port-forwarding, via the same reverse-tunnel approach described in `net-sec_doc.md`.
